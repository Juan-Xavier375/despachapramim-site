Política de Privacidade do Despacha Pra Mim

Vigente desde 6 de setembro de 2026

O Despacha Pra Mim é um sistema de gestão de entregas usado por restaurantes que têm frota própria de entregadores. Ele tem duas partes: um painel usado pela loja e um aplicativo Android usado pelos entregadores.

Esta política explica quais dados o sistema trata, por quanto tempo, e o que você pode pedir a respeito deles.

O sistema foi desenhado para guardar o mínimo possível. Nome, telefone e localizador de chamada do cliente são apagados 24 horas depois da criação do pedido, automaticamente.

Quem trata os dados

O restaurante que contrata o sistema é quem decide coletar os dados e para que usá-los. Nós fornecemos o software e processamos os dados em nome dele, seguindo as regras descritas aqui.

Quando o pedido vem de uma plataforma de delivery, é a plataforma que coleta os dados do cliente e os repassa ao restaurante. Nós apenas recebemos o que é necessário para a entrega acontecer.

Dados do cliente que faz o pedido

Para uma entrega acontecer, o sistema recebe e armazena temporariamente:

  • Nome
  • Telefone ou localizador de chamada
  • Endereço de entrega, incluindo complemento e ponto de referência
  • Valor a cobrar e forma de pagamento

Esses dados são apagados 24 horas após a criação do pedido. A exclusão é automática, roda todos os dias, e não depende de solicitação. O registro do pedido em si permanece — valor, taxa, horário — porque o restaurante precisa dele para fechar o caixa e acertar com o entregador. Mas ele deixa de estar associado a uma pessoa identificável.

Dados do entregador

Cada entregador tem uma conta criada pelo restaurante, com e-mail e senha. A senha é armazenada de forma protegida e não pode ser lida por nós nem pelo restaurante.

O aplicativo mostra ao entregador as entregas atribuídas a ele, o valor de cada taxa e o histórico dos turnos em que trabalhou. Esse histórico existe para que ele possa conferir o próprio acerto — e, como os dados do cliente já foram apagados, ele mostra endereço e valores, nunca o nome de quem recebeu.

O que o sistema não faz

  • Não rastreia a localização do entregador. O aplicativo não coleta nem envia a posição do aparelho para nenhum servidor.
  • Não usa ferramentas de análise de comportamento, publicidade ou relatório automático de falhas. Nenhum dado é enviado a terceiros com essas finalidades.
  • Não vende nem compartilha dados com terceiros para fins comerciais.
  • Não monta cadastro de clientes. Os dados existem para a entrega acontecer e são descartados depois.

Onde os dados ficam

Os dados são armazenados em servidor localizado no Brasil, com acesso restrito. A comunicação entre o aplicativo, o painel e o servidor é criptografada.

Seus direitos

A Lei Geral de Proteção de Dados (Lei 13.709/2018) garante a você o direito de confirmar se tratamos seus dados, acessá-los, corrigi-los, pedir a exclusão e saber com quem foram compartilhados.

Para pedidos relacionados a uma entrega, procure primeiro o restaurante — é ele quem tem a relação com você e quem decide sobre esses dados. Se preferir falar conosco diretamente, use o contato abaixo.

Na prática, a maior parte dos pedidos de exclusão já estará atendida antes de chegar: os dados pessoais de um pedido não sobrevivem mais de 24 horas no sistema.

Mudanças nesta política

Se o sistema passar a tratar dados de forma diferente, esta página é atualizada antes da mudança entrar em vigor, e a data de vigência no topo muda junto.
